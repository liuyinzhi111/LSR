一
你见过颜色"逃跑"吗？
⏱ ~40秒

想象一下：你正在修复一座老旧的钟，手指触到表盘上剥落的彩绘，下一秒——你掉进了另一个世界。

赭石变成褐，褐变成灰，灰变成虚无。这个世界的颜色，正在一点一点地逃走。

这就是《失色纪·修钟人》的开场。一个画师，一座褪色的异世界，还有只剩三天的时间。

二
这是一款什么游戏？
⏱ ~40秒

《失色纪·修钟人》是一款网页端生存解谜游戏，可以直接在手机或电脑的浏览器里玩，不需要下载任何东西。

玩法核心很简单：在一个正在褪色的世界里，采集资源 → 合成道具 → 修复古钟。但挑战在于——你只有三天，而夜晚的黑暗会不断吞噬你的颜色。

游戏参考了《星露谷》的采集节奏、水墨插画的美术风格，同时加入了独特的叙事设计：胜利不是凯旋，失败不是"你死了"——一切都用物质性的笔触描述。

三
最有趣的设计：颜色就是生命
⏱ ~60秒

游戏没有传统的"血条"，而是用三种物质状态来表示你的存活程度，每一项都和世界主题直接相关：

🎨
色值
画师的颜色浓度
归零即灰化消亡
🖋️
墨韵
精神韧性
归零无法行动合成
🕯️
纸温
身体的物质温度
归零色值加速流失

这三项数值之间互相影响，形成有趣的策略层次——补充哪一项、何时补充，都是玩家需要实时判断的问题。

五
两种结局，两种感受
⏱ ~40秒

修复成功：钟响了，不是欢呼的响，是"放还"的响。靛蓝从裂缝渗出，赭石漫回袖口，但指缝里还嵌着褪色界的土——你回来了，但有些东西留下了。

颜色耗尽：你不会看到"Game Over"。你的轮廓越来越淡，越来越透明，最终成为褪色界那圈仰头站立的透明人群像中的一员——永远在等待下一个修钟人。

两个结局都设计了完整的交互动画序列，共计25个叙事节点，配合实时生成的音乐和粒子特效。

六
为什么说它在技术上很特别？
⏱ ~50秒

作为一款网页游戏，《失色纪·修钟人》有一个不寻常的技术决策：

🎨
零图片资源
所有视觉——草地、怪物、钟塔、粒子特效——全部由 Canvas 代码路径实时绘制，没有任何外部图片文件
🎵
实时音乐合成
所有背景音乐和音效均由 Web Audio API 实时生成，C小调八音盒旋律随昼夜动态变化，无任何音频文件
📦
零框架依赖
不使用 React、Vue、jQuery 等任何框架，纯原生 JavaScript，代码完全透明可读
📱
全平台适配
PC 键鼠与手机触屏双模式，虚拟摇杆非线性速度曲线，成就系统提供跨局永久加成

简单说：这款游戏是用代码"画"出来的、"弹奏"出来的，每一帧画面、每一个音符都是运行时实时计算的结果。
