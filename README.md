# 刘盛瑞 · 个人作品集

当前版本以原始提交 `0a88bd92e88aba9e8c0e7a4bd08e370ba84b9564` 的设计为基础，保留原配色、字体、页面布局、开场、视频转场、滚动卡片和联系区。恢复原版之后的性能及交互调整记录如下。

工程层保留 Next/React 与检查工具升级、单一 Next 配置、本地静态预览，以及少量不改变视觉的类型、effect 依赖和请求状态检查。

2026-10-26 随后的卡顿修复保留原版外观：视频新增 H.264 网页播放副本，原始 `intro.mp4` 保留；阴影改为独立图层；开场字母与背景色过渡改用位移/透明度；被遮住或滚出屏幕的视频暂停。实测数据见验收记录。

针对首次播放，视频会在开场内短暂预解码；全屏视频完全覆盖的首页跑马灯层暂不绘制，滚动露出时恢复。正式展示仍从视频开头开始，开场时间与原设计一致。

装饰动画的 8 处持续 JavaScript 循环已改为浏览器原生 CSS 动画，保留各自的轨迹、时长和缓动。全屏视频遮住跑马灯及背景线条时暂停它们；滚动露出时恢复，标签页隐藏时暂停。鼠标光效只更新当前区域，并合并同一帧内的鼠标移动。作品图片和工具图标使用延后加载与异步解码，减轻首屏负担。

滚动区间已按“画面流畅，但需要滚太多才推进”的反馈缩短：视频 600→300vh、能力卡片 300→240vh、作品 300→220vh、工具区 200→160vh。视频按实际固定区间映射原关键帧，保证签名和落款在离开视频段之前完整展示；动画样式和内容保留。

针对 About Me 和能力区交互迟钝，鼠标光晕改为移动小图层，点阵高亮只更新指针附近的小块区域；字母说明立即交叉切换，能力卡片通过 transform 移动，缩短跟随和弹簧的拖尾。标题进入视口后更早响应。该轮没有继续改变页面高度、配色、字体或卡片最终位置；浏览器验证与测量限制见验收记录。

## 运行

需要 Node.js 20.9 或以上版本。

```powershell
npm ci
npm run dev
```

生产构建预览：

```powershell
npm run build
npm start
```

地址：http://127.0.0.1:3000。更换端口：`npm start -- --port 3003`。

## 检查

```powershell
npm run lint
npm run typecheck
npm test
```

`npm test` 需先构建，验证当前页面的本地链接/资源以及静态服务和视频分段请求，使用临时端口并在测试结束时关闭服务。
